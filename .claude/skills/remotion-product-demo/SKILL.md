# Remotion product demo

Follow `remotion-setup` first.

1. Default to 30 seconds. Scenes: problem, solution, three feature callouts, call to action.
2. Build a reusable faux browser window component with an animated cursor and click ripples.
3. Add a second 1080x1920 composition that reuses the same scene components (see `remotion-social-formats`).
4. Keep product name, claims and callouts in the data file; do not invent metrics or customer claims, ask for them.
5. Render stills per scene and check before finishing.
